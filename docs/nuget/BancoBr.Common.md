# BancoBr.NET — Domínio compartilhado

Tipos, enums e contratos compartilhados pelas integrações bancárias API e CNAB 240 do BancoBr.NET.

Fornece os modelos de correntista, favorecido e movimento, além dos enums, atributos e interfaces usados pelos pacotes BancoBr.API e BancoBr.CNAB.

## Compatibilidade

Biblioteca com alvo .NET Standard 2.0.

## Instalação

Configure o feed GitHub Packages do proprietário que publicou a versão desejada e execute:

```sh
dotnet add package BancoBr.Common --version VERSAO
```

Use uma versão disponível no feed configurado. Versões com sufixo `fork` são distribuições do fork.
